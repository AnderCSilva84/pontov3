Use um aparelho/conta de teste e o grupo demonstrativo autorizado, com dados fictícios. Não use um registro de ponto real para o ensaio. Antes de trocar a versão, confira operações offline pendentes. Se o Android recusar a atualização, registre o erro e não desinstale o app com pendências para contornar o problema.
